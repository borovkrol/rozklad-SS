# Розклад СС-25-1фмб-hm

Це готовий статичний сайт для GitHub Pages.

## Як опублікувати
1. Створи на GitHub новий public repository, наприклад `rozklad-ss-25-1fmb-hm`.
2. Завантаж у корінь репозиторію `index.html` та `manifest.webmanifest`.
3. Відкрий Settings → Pages.
4. У Source вибери `Deploy from a branch`.
5. Branch: `main`, папка: `/ (root)`.
6. Натисни Save.
7. GitHub покаже адресу сторінки. Відкрий її в Chrome на Android.
8. У Chrome: ⋮ → «Додати на головний екран» / «Встановити застосунок».

Понеділок 3–4 пари залишені з варіантами, оскільки у вихідному розкладі не вказано, який варіант припадає на який тиждень.
